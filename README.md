# AI-Powered Sales Forecasting Dashboard

## Project Overview
This project builds an AI-powered sales forecasting system using historical retail sales data.
The goal is to analyze trends, seasonality, and predict future sales using Machine Learning
and visualize results in Power BI.

## Tools & Technologies
- Python (Pandas, Scikit-learn / Prophet)
- Matplotlib
- Power BI
- GitHub

## Dataset
Retail sales dataset containing:
- Sale_Date
- Sales_Amount
- Product, Region, Channel details

## Methodology
1. Data cleaning & preprocessing
2. Time-series analysis
3. Trend & seasonality detection
4. Sales forecasting model
5. Visualization using Power BI forecast analytics

## Dashboard Features
- Actual Sales vs Forecast
- Trend line
- Confidence interval (95%)
- Time-based analysis

## Files in this Repository
- `sales_forecasting.ipynb` – ML forecasting code
- `sales_data.csv` – Dataset
- `sales_forecast_dashboard.pbix` – Power BI dashboard
- `forecast_dashboard.png` – Dashboard preview

## Result
Successfully built a forecasting model and an interactive Power BI dashboard
showing future sales trends and seasonality.
